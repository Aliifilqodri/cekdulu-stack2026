# cekdulu 📍

> cek dulu, baru berangkat.

pernah ke kelurahan terus ternyata blanko e-ktp habis? atau ke rumah pak rt malem-malem buat minta tanda tangan, eh orangnya lagi pergi?

cekdulu itu peta kondisi layanan di sekitar kita **saat ini**, dari rt sampai kelurahan. datanya dari laporan sesama warga, bisa lewat web atau cukup chat whatsapp.

dibikin buat **stack 2026** (case 2: stronger communities and everyday services) sama tim **bakmi bangka pedas 2**.

> repo ini masih kerangka. kode dibangun bertahap, progresnya bisa dilihat di [`docs/tugas.md`](docs/tugas.md).
