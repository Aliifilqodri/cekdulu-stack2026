# cara kerja bareng

- `main` jangan di-push langsung, harus lewat pull request
- kerja di branch sendiri: `feat/peta-marker`, `fix/otp-expired`, dst
- pr ke `dev` dulu, minta satu orang review
- commit pake huruf kecil: `feat: marker pake warna status`
- `.env` sama token wa jangan pernah di-commit, kirim lewat chat pribadi
- kalau dibantu ai, tulis di deskripsi pr (nanti direkap di readme)
- abis kelar satu tugas, centang di `docs/tugas.md`
